# Splitting the Same-Day Patent Value

A short note extending Kogan, Papanikolaou, Seru and Stoffman (2017),
*Technological Innovation, Resource Allocation, and Growth*, QJE 132(2).

The KPSS patent value measure divides a firm's stock-market reaction equally
across every patent it is granted on the same Tuesday. This note replaces that
`1/N` split with weights proportional to the patent similarity ratio of Kelly,
Papanikolaou, Seru and Taddy (2021). The weights sum to one within each
firm-day, so firm-level and aggregate measures are unchanged; only the
patent-level allocation moves.

Sample: 1926–2010, 1,801,301 patents.
